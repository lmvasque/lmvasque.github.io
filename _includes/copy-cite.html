{% comment %} Copy-to-clipboard for the Cite / BibTeX buttons. Include once per page. Inline on purpose: assets/js/main.min.js is a committed build artifact and assets/js/_main.js is excluded from the Jekyll build, so editing the JS sources would also require running `npm run build:js` and committing the rebuilt bundle. This keeps the feature self-contained. A button carries the text to copy in data-clip; the browser has already decoded the newline entities by the time JavaScript reads it. One delegated listener covers every button on the page. Use /* */ comments only, never //. `layout: compress` strips newlines from the whole page, including this script, so a // comment silently comments out the entire remainder of the file and the buttons stop responding. {% endcomment %}
